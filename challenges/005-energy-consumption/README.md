# Desafio #05 — Consumo Diário de Energia

**Tech Sisters · Desafio de Código**

## Sobre o desafio

Desenvolver um programa para acompanhar o consumo diário de energia de uma residência durante um determinado período.

O programa solicita a quantidade de dias analisados, o consumo de cada dia em kWh e um limite de consumo médio diário definido pelo usuário.

Ao final, calcula o consumo total, a média diária e verifica se o consumo médio ultrapassou o limite estabelecido.

## Requisitos

* Solicitar a quantidade de dias analisados, aceitando apenas valores maiores que zero.
* Solicitar o consumo diário em kWh, não permitindo valores negativos.
* Calcular o consumo total e a média diária.
* Comparar a média diária com o limite informado pelo usuário.
* Exibir uma mensagem indicando se o consumo ficou acima ou dentro do limite.

## Conceitos abordados

* Laços de repetição.
* Validação de dados.
* Funções e métodos.
* Estruturas condicionais.
* Programação orientada a objetos.

## Implementação

A solução foi desenvolvida em **PHP**, utilizando programação orientada a objetos para representar os consumos diários e centralizar os cálculos e as regras de validação.

## Como executar

É necessário ter o PHP instalado e disponível no terminal.

```
php consumo.php
```

## Exemplo de execução

```
Quantidade de dias: 3
Consumo do dia 1 (kWh): 10
Consumo do dia 2 (kWh): 12
Consumo do dia 3 (kWh): 14
Limite diário (kWh): 11

Consumo Total: 36 kWh | Média Diária: 12 kWh
Atenção: consumo médio ACIMA do limite estipulado (11).
```
